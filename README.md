# Confidently Wrong about the Long Tail — companion repository

Companion to: Markos Konstantakis (2026). *Confidently Wrong about the Long Tail: Popularity, Grounding and
Language in Multilingual LLM Museum Guides.* Manuscript submitted to ACM Journal on Computing and Cultural Heritage.
Preregistration: [OSF ANX4T](https://doi.org/10.17605/OSF.IO/ANX4T).

- **`docs/`** — interactive companion page (findings, anatomy of three hallucinations, the record tool in the
  browser). Published with GitHub Pages from the `docs/` folder.
- **`tool/`** — `explicit-record`, a standard-library Python tool that makes documented absence explicit in museum
  records (Europeana items or plain record text) before an LLM answers from them. See `tool/README.md`.

The study data (questions, answers, labels, analysis code) are archived separately on Zenodo: [DOI to be added].
